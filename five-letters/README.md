# 5 букв

Помощник для игры «5 букв» (русский Wordle): подсказывает, какие слова ещё подходят и каким словом
ходить дальше. Есть сайт (`site/five-letters/`, JS) и консольная версия (эта папка, Go).

## Правила игры

Загадано слово из 5 букв. Ты называешь слово из 5 букв, и игра красит каждую букву:

- **зелёная** — буква на своём месте;
- **жёлтая** — буква есть в слове, но стоит не там;
- **серая** — такой буквы нет в слове (или она встречается в слове реже, чем в попытке).

По цветам нужно угадать слово за ограниченное число попыток. «Ё» считается за «е».

## Сайт

1. Введи слово, которое назвал в игре, и нажми «Добавить».
2. Нажимая на буквы, раскрась их как в игре: серая → жёлтая → зелёная.
3. Смотри список подходящих слов и лучшие следующие ходы. Повторяй с шага 1.

Попытки хранятся в адресе страницы (`#норка.01200`), так что ссылкой можно поделиться.
Свой словарь можно выбрать на странице: текстовый файл, одно слово в строке.

Цвета считаются по правилам Wordle, включая повторы букв. Ход оценивается так: слово разбивает
оставшихся кандидатов на группы по цветам, оценка — сумма квадратов размеров групп, делённая на число
кандидатов (меньше — лучше). Перебирается весь словарь; при равенстве выигрывают слова, которые сами
могут быть ответом.

На встроенном словаре лучший первый ход — «норка» (в среднем остаётся 101 слово из 3473);
хорошая тройка для старта — «терка», «силон», «падуб».

## Консольная версия

Из корня репозитория:

```sh
go run ./five-letters -mask '.н..а' -wrong 'и' -tries 'салют,барин,мечта,знать'
```

```
Подходящих слов: 7
гнида
жнива
...
```

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `-mask` | `.....` | Буквы на известных позициях («зелёные»), `.`, `_` или `*` — неизвестно. |
| `-wrong` | пусто | Буквы, которые есть в слове, но стояли не на своих местах («жёлтые»). |
| `-tries` | пусто | Предыдущие попытки через запятую или пробел. |
| `-n` | 20 | Сколько слов вывести. |
| `-dict` | встроенный | Свой словарь: одно слово на строку, UTF-8. |

Регистр не важен, `ё` считается за `е`. Ошибки ввода — сообщение в stderr и код возврата 2.

Из ввода получаются такие ограничения:

- буквы попыток, которых нет ни в маске, ни в `-wrong`, в слове отсутствуют («серые»);
- если буква попытки на позиции i не совпадает с маской, на позиции i её нет;
- каждая буква из `-wrong` должна встретиться в слове.

Ограничение: не учитывается, сколько раз буква встречается в слове. Если `а` и зелёная, и жёлтая,
слову хватит одной `а`. Сайт эту ситуацию разбирает точно.

## Словарь

`words.txt` — существительные из 5 букв из `russian_nouns.txt`, `ё` заменена на `е`, дубли убраны.
Сгенерирован так:

```sh
LC_ALL=en_US.UTF-8 grep -E '^[а-яё]{5}$' /Users/rve/Documents/agent-work-dir/misc/russian_nouns.txt \
  | LC_ALL=en_US.UTF-8 sed 's/ё/е/g' | awk '!seen[$0]++' > five-letters/words.txt
```

Сайт скачивает тот же файл: `site/five-letters/words.txt` — символьная ссылка на `five-letters/words.txt`
(при деплое она превращается в обычный файл).
Файл, переданный через `-dict` или выбранный на сайте, фильтруется так же: остаются слова ровно из
5 русских букв.
